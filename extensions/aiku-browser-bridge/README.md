# aiku AI Memory Bridge (Chrome / Edge Extension)

Extension ringan 100% lokal ini menghubungkan obrolan Anda di **Gemini Web** (`gemini.google.com`), **ChatGPT**, dan **Claude** langsung ke **Live Wallpaper Knowledge Graph** milik `aiku` (`http://127.0.0.1:47891`).

## Cara Pasang (30 Detik)
1. Buka **Chrome** (`chrome://extensions`) atau **Edge** (`edge://extensions`).
2. Aktifkan **Developer mode** (kanan atas).
3. Klik **Load unpacked** → pilih folder `extensions/aiku-browser-bridge` ini.

Selesai! Setiap kali Anda mengobrol di Gemini Web sambil menjalankan `aiku`, node konsepnya otomatis muncul dan terhubung dengan AI Lokal & Antigravity di wallpaper laptop Anda.
